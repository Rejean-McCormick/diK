# Exemples de contrats — localisation de ressources

Les fichiers de ce dossier sont des **modèles documentaires non normatifs**, non reconnus automatiquement par le CLI diK V3 et non activables tels quels. Ils **ne sont pas** des catalogues Framework `schema_version=11.0`, des crosswalks acceptés ni des listes de fichiers vérifiés sur la machine actuelle.

- `source-registry.example.json` : état de découverte et contrôle d'accès à des ressources externes ; `enabled=false` pour toutes.
- `lexical-resolution.example.json` : résultat fictif d'une résolution, sans forme réelle ni alignement Wikidata certifié.

Les chemins Windows de l'exemple sont des pistes tirées d'index et de la documentation, pas des attestations d'existence. Toute implémentation doit valider la source, l'intégrité, la provenance, la licence, l'alignement et la politique d'activation. Voir [36](../../docs/36_SOURCE_MANAGER_LOCAL_ET_REFERENCES.md).
