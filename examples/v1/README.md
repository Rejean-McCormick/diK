# Exemples diK 1.0 alpha

`roles-legacy.example.json` démontre le principe : **l'opérateur** identifie les champs qui contiennent réellement des références sémantiques. diK ne remplace pas aveuglément tous les mots d'un document.

Exécuter ensuite `dik legacy plan --project ... --source ... --index ... --roles ... --locale fr --output plan.json`. Le plan est non exécutable; ne jamais publier automatiquement une nouvelle version canonique à partir de ce fichier.
